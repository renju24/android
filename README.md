# Рендзю — Android-приложение

Учебный проект (Go+Android+Web). Клиентская часть приложения для игры в рендзю (пять в ряд) на платформе Android.

---

## О проекте

Рендзю — классическая логическая игра на доске 15×15, где два игрока по очереди ставят чёрные и белые камни. Цель: первым построить непрерывный ряд из 5 своих камней по горизонтали, вертикали или диагонали.

Приложение предоставляет полноценную игровую платформу с системой авторизации, профилями пользователей и системой приглашений для игры с другими игроками.

---

## Функциональность

### Авторизация и регистрация
- Регистрация нового пользователя
- Вход по логину/паролю
- Авторизация/регистрация через OAuth2
- Выход из аккаунта

### Профиль пользователя
- Просмотр и редактирование личной информации
- История сыгранных партий
- Общий рейтинг игроков

### Система приглашений
- Отправка приглашений другим пользователям на игру
- Просмотр входящих приглашений
- Принятие или отклонение приглашений

### Игровой процесс
- Игровое поле 15×15
- Пошаговая игра между двумя игроками
- Подсветка последнего хода
- Проверка победы после каждого хода
- Определение ничьей
- Отображение текущего игрока и статуса игры

---

## Технологии

- **Язык:** Kotlin
- **Минимальная версия Android:** 4.4 (API 19)
- **Архитектура:** MVVM
- **Сетевое взаимодействие:** Retrofit, OkHttp
- **WebSockets:** Centrifuge
- **Сериализация:** Gson
